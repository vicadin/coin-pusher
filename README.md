# Coin Pusher 🪙

Coin Pusher is a lightweight HTML5 playable ad featuring custom 2D arcade physics, dynamic coin cascades, Web Audio API sound synthesized effects, procedural particle juice, and jackpot CTA modal.

## Demo
🌐 https://vicadin.github.io/coin-pusher/

## Tech Stack
- TypeScript
- PixiJS
- Vite
- HTML5
- CSS3
- Web Audio API

## Installation & Execution
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
